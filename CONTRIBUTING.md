# Contributing to Trikomi Vanilla JS Showcase

Thank you for contributing to the **Trikomi Vanilla JS** e-commerce demonstration suite!

---

## 🌟 How Developer Enthusiasts Can Contribute

### 1. Zero-Framework UI Polish
- Enhance standard HTML5, CSS3, and JavaScript ESM implementations (`app.js`, `styles.css`).
- Build new theme layouts or improve touch/mobile performance.

### 2. E-Commerce Integration Samples
- Submit Liquid snippet references for Shopify.
- Submit WordPress/WooCommerce plugin snippets binding `trikomi.esm.js` to product options.

---

## 🛠️ Contribution Workflow

1. Fork the repository.
2. Make your edits in a feature branch.
3. Test locally in any browser (e.g. `npx serve .` or Live Server).
4. Submit a Pull Request on GitHub!

Contributors with merged PRs will be featured on [victorshell.com/partners](https://victorshell.com/partners).
